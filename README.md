# מתכונים מהגינה — רחל ומודי

ספר המתכונים של גינת הגג כאפליקציית טלפון (PWA).

**כתובת:** https://modiaviram-arch.github.io/garden-recipes/

## התקנה בטלפון
- **אייפון (Safari):** פותחים את הכתובת → כפתור שיתוף → "הוסף למסך הבית".
- **אנדרואיד (Chrome):** פותחים את הכתובת → תפריט ⋮ → "הוסף למסך הבית" / "התקן אפליקציה".

האפליקציה עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה. מועדפים ורשימת קניות נשמרים בטלפון.

## עדכון
מחליפים את `index.html` ומעלים גרסה חדשה (ומעדכנים את שם ה-cache ב-`sw.js`).
